# Ghazni Afghan Kabobs website

Static site (no build step). Open `index.html` or deploy the folder to Vercel/Netlify.

- `js/config.js` is the one file to edit for hours, phones, menu items, catering prices and **online-ordering URLs**.
- `img/` is empty: add real photos and set them on the `.ph` blocks (currently branded placeholders).
- Hero background is a live canvas (embers + connecting grid that reacts to the pointer); it pauses off-screen and respects reduced-motion.
